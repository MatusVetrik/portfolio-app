# 06 — Performance, Accessibility, SEO

## Quality tiers
Detect once at load (re-evaluated by the adaptive monitor):
- Inputs: `navigator.hardwareConcurrency`, `deviceMemory`, GPU string via `WEBGL_debug_renderer_info` (+ `detect-gpu` lookup), screen size/DPR, `pointer: coarse`, battery saver hint, measured first-second frame time.
- `high`: desktop discrete/modern GPU. `mid`: integrated GPU / good phones. `low`: weak devices, tiny viewports.

| Setting | low | mid | high |
|---|---|---|---|
| DPR cap | 1 | 1.5 | 2 |
| Particles | 25% | 60% | 100% |
| Shadows | off | baked-look only | soft shadows |
| Post-FX | CSS overlays | bloom+grain | full (see 02) |
| Physics | off | ≤ 15 bodies | ≤ 30 bodies |
| Transition shader | fade+scale | full | full + flourish |
| Antialias | off | MSAA 2x | MSAA 4x / SMAA |

Runtime: `PerformanceMonitor` lowers tier one step if avg fps < 45 (desktop) / 28 (mobile) for 2 s; never auto-raises more than once per session. A visible "Quality" toggle (Auto/Low/Mid/High) lives in the FastPathBar overflow menu.

## Budgets
| Item | Budget |
|---|---|
| Initial JS (shell + core + first world) | ≤ 600 KB gzip |
| Each additional world chunk | ≤ 150 KB gzip |
| Total textures | 0 (procedural) — generated noise textures ≤ 1 MB GPU |
| Fonts | ≤ 150 KB total (subset, `font-display: swap`) |
| Audio (lazy, after first sound-on) | ≤ 1.5 MB total |
| Triangles per world (visible) | high ≤ 250k · mid ≤ 120k · low ≤ 50k |
| Draw calls per world | ≤ 150 (use instancing/merged geometry) |
| Frame time | 16.6 ms desktop · 33 ms mobile |
| Time to first interactive frame | ≤ 3 s broadband |

Techniques: `InstancedMesh` for rocks/stars/keys, merged static geometry, shared materials, `drei` `<Preload>` per world only for next neighbour, dispose on unmount, frustum culling, avoid per-frame allocations, shader-based particles.

## Mobile
- Layout: HUD collapses to a pill; FastPathBar becomes a bottom sheet; Panel is a full-height sheet.
- Touch: scroll = dive; one-finger drag on throwables = throw; gyro drift opt-in.
- Safe-area insets respected; `100dvh`; no hover-only affordances (tap shows label then second tap opens).
- Visual parity target: ~80% — fewer particles/objects, same camera moves and transitions.

## Accessibility
- `prefers-reduced-motion` → stepped mode (03). Also an explicit in-app "Reduce motion" toggle.
- Full keyboard path: skip link → FastPathBar → JumpMenu → content objects (mirrored DOM buttons) → Panel (focus trap, ESC).
- Canvas has `role="img"` + `aria-label` summary; real content is exposed in a visually-hidden DOM mirror ordered by world, updated with the active world (`aria-current`).
- Panel text is real DOM, ≥ 4.5:1 contrast, resizable up to 200% without loss.
- No autoplay audio; sound toggle is labelled, state announced.
- Avoid seizure risk: no >3 flashes/sec; flourishes are single bursts and disabled in reduced motion.
- `Plain view` (`/cv`) is a first-class accessible alternative with print stylesheet.

## SEO / sharing
- Prerendered HTML with name, headline, structured data (`Person` JSON-LD, `sameAs` links), meta description from `profile.pitch`, canonical URL.
- Open Graph / Twitter image: a pre-rendered still of the hero world (generated by Playwright at build, M7).
- `robots.txt`, `sitemap.xml`, favicon + theme-color from tokens.

## Audio policy
Off by default; first user toggle persists in `localStorage`; unlock `AudioContext` on that click; all volumes ≤ -12 dBFS; ducks when tab hidden; assets CC0 with attributions in `docs/credits.md` (created at M6).

## Privacy
No analytics in v1 (or privacy-friendly, cookieless, added later). Gyro/orientation permission only on explicit tap.
